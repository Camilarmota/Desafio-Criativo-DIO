# Desafio Criativo: Simplificando Tarefas e Ganhando Foco com IA

Este repositório contém as instruções do **Desafio Criativo**, uma atividade prática voltada para a construção de *prompts* claros, estruturados e eficientes para Inteligência Artificial, acompanhado do prompt refinado gerado a partir dessa metodologia.

---

## 🎯 Sobre o Desafio

Um bom *prompt* nasce de intenção clara, contexto bem definido e instruções específicas. O objetivo do **Desafio Criativo** é guiar o usuário na organização de suas ideias, transformando intenções genéricas em comandos precisos capazes de orientar a IA a produzir o resultado esperado.

---

## 🧩 Instruções do Desafio (Passo a Passo)

### 🧱 Passo 1: Defina a Intenção
Nesta etapa, descreve-se o que a IA deve gerar, o público-alvo e o resultado esperado.

* **Perguntas de orientação:**
  * O que você quer gerar?
  * Para quem é o conteúdo?
  * Qual o resultado esperado?
* **Modelo para adaptação:**
  ```text
  Quero que a IA gere [tipo de conteúdo] para [público], com o objetivo de [resultado].
  ```
* **Exemplo de aplicação:**
  * *"Quero que a IA gere uma lista de tarefas para estudantes, com o objetivo de melhorar a organização dos estudos."*

---

### 🧱 Passo 2: Adicione Contexto e Restrições
Nesta etapa, detalha-se como a resposta deve ser construída, definindo tom, formato e limitações.

* **Perguntas de orientação:**
  * Qual estilo deseja?
  * Tem limite de tamanho?
  * O que deve evitar?
* **Modelo para adaptação:**
  ```text
  Considere o seguinte contexto: [contexto]. O conteúdo deve ter [formato]. Evite [o que evitar].
  ```
* **Exemplo de aplicação:**
  * *"Considere o seguinte contexto: rotina de estudos diária. O conteúdo deve ter formato de lista simples. Evite linguagem técnica."*

---

## 🚀 Prompt Refinado

Aplicando os passos do desafio para o ensino de programação básica em Python, foi estruturada a seguinte versão refinada do prompt:

> *"Atue como um tutor de programação didático e paciente. Crie um texto em tópicos voltado para pessoas totalmente leigas que querem aprender a base de algoritmos e lógica usando Python.*
> 
> **Requisitos:**
> - **Linguagem:** Simples, direta e sem jargões técnicos complexos (se precisar usar algum termo técnico, explique-o de forma simples).
> - **Analogias:** Use exemplos do cotidiano (como uma receita de bolo) para explicar o que é um algoritmo.
> - **Estrutura:** Divida o conteúdo em tópicos claros (conceito de algoritmo, variáveis, tomadas de decisão e repetições).
> - **Exemplos:** Inclua pequenos exemplos de código Python simples e comentados."*
